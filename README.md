El MGD es una institucionalidad imaginaria que se encarga de dibujar los problemas y develar mecanismos para que el drama no se instale en el centro.

Creemos que la burocracia nos puede ser funcional, y que reportar nuestros dramas puede transformarmse en una instancia de catarsis que nos ayude a aliviar la carga de lidiar con estos dramas cotidianos.

Notas:
* El MGD no guarda datos de ningún tipo
* La participación no garantiza la resolución de los dramas reportados
